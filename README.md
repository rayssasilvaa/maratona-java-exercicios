# Maratona Java

Repositório dedicado aos meus estudos de Java, reunindo códigos, exercícios e exemplos desenvolvidos durante as aulas de Maratona Java.

## Sobre o projeto

Este repositório funciona como um registro da minha jornada de aprendizado em Java, contendo implementações práticas dos conteúdos estudados em aula.

O objetivo é praticar, revisar conceitos e acompanhar minha evolução na linguagem, desde os fundamentos até assuntos mais avançados.

## Conteúdos estudados

Os códigos podem abordar diferentes conceitos da linguagem Java, como:

- Fundamentos da linguagem;
- Variáveis e tipos de dados;
- Estruturas condicionais e de repetição;
- Arrays e Collections;
- Programação Orientada a Objetos (POO);
- Métodos e construtores;
- Tratamento de exceções;
- Manipulação de datas;
- Streams e Optional;
- Outros conceitos abordados durante as aulas.
